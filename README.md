# Updated Prosema Mali Frontend

This frontend is configured to talk to the Finex Mali backend.

## Local Development

Run the backend on:

```bash
http://localhost:3001/market
```

The frontend runs on:

```bash
http://localhost:3000
```

## Environment

For local development, this repo uses:

```bash
REACT_APP_API_URL=http://localhost:3001/market
```

The API helper also defaults to `http://localhost:3001/market` when running on `localhost`.

## Available Scripts

### `npm start`

Starts the app on [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the app for production.

### `npm test`

Runs the test suite.
